# 11.2. Пул потоков

[Условие на uLearn](https://ulearn.me/course/java/Zadacha_11_2_ba0de434-d87d-4c3c-9610-005a1e6aa404)

В пуле три рабочих потока и три места в очереди, как задано в условии. Если рабочие заняты и очередь полна, обработчик передаёт задачу в `put()`. Вызов ждёт свободного места в очереди, поэтому цикл отправки замедляется и в работе по-прежнему участвуют только потоки пула.

Главный поток дожидается завершения каждой задачи через `Future.get()`. При успешном запуске последняя строка содержит `Total: 30`.

Откройте `pom.xml` в IntelliJ IDEA и запустите `PoolExample.main`. Для запуска теста выполните `mvn test`.
